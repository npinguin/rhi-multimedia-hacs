# RHI Multimedia

Integrated backend and Multimedia dashboard. Install `https://github.com/npinguin/rhi-multimedia-hacs` as one custom Integration. Enable prereleases, select the TEST version, restart HA and add the integration. Open your dashboard editor and select RHI Multimedia (existing `custom:homebrain-multimedia-card` also works). UX loads automatically; disable it through the integration options if headless. No second HACS package or manual resource. Requires Foundation for technical source selection; retain current room mappings and verify device readback. Supported HA OS/Container 2026.11.1 amd64/arm64. No stable or physical multiroom acceptance claimed. Back up before upgrade.
